### Changed

#### Go 1.26 is now the minimum

Org standards set Go 1.26 as the mandatory minimum and the default
(`.standards/instructions/go.md`). This repo was on `go 1.25.0`.

`go.mod` and every CI `go-version` pin are bumped together — leaving CI on an
older toolchain than `go.mod` declares means the version actually exercised by
tests is not the version the module claims to require.

Verified before bumping rather than after: `go build ./...` and `go vet ./...`
both exit 0 under Go 1.26.
